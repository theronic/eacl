# EACL-FORMAL-025 — whole-graph work was promoted to query-local work

The materializing semantic oracle computes the least fixed point for the whole
finite fixture and then projects the requested answer. Production and the
generated indexed engine seed only work relevant to the query's subject type
and permission root.

An unrelated direct team grant therefore contributes to the materialized
oracle's initial pending set but not to a user query's indexed queue. Under
`:max-queued-work 1`, the whole-graph model can return a typed limit while the
query-local engine correctly completes. This is not an authorization-set
disagreement; it is a resource-scope disagreement.

The assurance boundary now compares materialized and indexed authorization
values only when both complete. Operational limits and resource counters are
compared only between the generated indexed state machine and production,
where unit, scope, and clock match.
