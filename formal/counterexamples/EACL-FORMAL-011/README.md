# EACL-FORMAL-011 — reverse consumer registration escaped resource refinement

The smallest witness is a reverse recursive lookup whose root permission
contains a self-permission edge. The host evaluator installed the reverse
consumer immediately and queued only its goal. The generated engine queued a
consumer-registration work item followed by the goal.

Authorization values agreed, so result-only shadowing missed the mismatch.
Lore-style dimensional comparison exposed it: generated cumulative enqueues
and peak queue depth were each one larger. Both counters had the same names and
units, but the transition systems did not account for the same work.

The host evaluator now uses the generated FIFO transition. Cache-free shadow
mode compares all dimensionally matching counters and logical retained-state
units independently from result values. Cached and uncached executions are not
compared as if their resource costs should be equal.
