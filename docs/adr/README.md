# Architecture decision records

Numbered ADRs from the v6/v7 era (001–012). They remain the record of why
each decision was taken at the time; several describe implementations that
the v8 stable-discovery engine has since replaced (Datalog rules,
`index-range` optimizations, recursive graph traversal by fixed point). Read
them as history; the current engine contract is
[`../stable-discovery-engine.md`](../stable-discovery-engine.md).
