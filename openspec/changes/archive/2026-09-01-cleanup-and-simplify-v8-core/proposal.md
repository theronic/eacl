## Why

The v8 engine accumulated additively: fresh code-grounded surveys (not the planning docs) show invariants re-validated per tuple that were already established at request admission or plan-seal time — worst case a SHA-256 digest of the entire operator plan recomputed for **every emitted result row** (`engine/v8.cljc:1718`) and the cover plan fully re-sealed per page (`engine/v8.cljc:1677,1942`) — plus formal machinery leaking into the request path (a runtime differential oracle in `verified_kernel.cljc:2185-2329` that recomputes kernel answers in Clojure and compares, per request), assurance gates that cannot fail (a selftest true by construction, 15 mutation controls decidable from adjacent literals, a replay gate silently skipping 18/67 entries), three orphan namespaces, and un-idiomatic hot code contradicting `.rules/clojure-rules.md`. A behavior-preserving cleanup pass removes this while keeping every certification gate green.

## What Changes

- **Hoist hot-path checks to their owning boundary** (no observable behavior change; error surfaces preserved):
  - Compute the operator cursor-scope digest once per page instead of per emitted row; memoize `cover-plan/seal-plan` in the existing `:sealed-plans` schema-cache partition (currently re-sealed per page, and per count-page in a loop).
  - Collapse the 2–3× candidate re-normalization between `check-cached-many-eids` → `check-many-eids` → misses; validate the probe descriptor once per group instead of per probe in `direct_membership`; seal plan-invariant properties (`expression-roots`, acyclicity) into the operator plan at compile time instead of re-deriving per candidate.
  - Remove per-bit `check-index!` from `bitmask` operations (width validated at construction); stop allocating diagnostic maps for `execution/check!` on the success path; collapse the `exact?`+`natural?` double predicate; give `backend/invoke` the fixed-arity treatment its siblings `scan-invoker`/`direct-match-invoker` already have.
  - Batch-check API: read the 5 consumed counter slots directly instead of building four 20-entry maps per check; use the existing fast `memoized-active-state!` path.
- **Remove formal re-derivation from the production request path**: drop the `expected-*` recompute-and-compare chain from `invoke-kernel` (line-for-line duplicates of `portable_decisions`; a tautology on CLJS where the kernel *is* that namespace; not listed in the assurance contract's `:boundary-invariants`). The mandated FFI boundary (`validate-input!`/`validate-result!`) and the constant-work live-page bounds checks stay. The equivalent comparisons already run offline in the differential suites; mutation controls currently "killed" by these duplicates are re-pointed at genuine gates.
- **Idiomatic and performance fixes per `.rules/clojure-rules.md`**: pre-sort consumer buckets once instead of `pr-str` inside the innermost sort comparator; apply the decorate-sort-undecorate pattern (already implemented and measured in `sealed_plan.cljc:191`) to the 5 remaining expensive-key `sort-by` sites; `volatile!` for single-thread request-local accumulation (matching existing usage); collapse byte-identical `#?(:clj :cljs)` branches; `count`-based emptiness on vectors in per-transition loops; `rseq` over `reverse`; hoist loop-invariant lookups; deduplicate the 5 copies each of `add-stat!`/`invalid!` and shared adapter scan-option normalization; remove stale `:refer-clojure :exclude` entries for symbols that don't exist; fix core-shadowing bindings and the two distinct dynamic vars both named `*aggregate-work-stats*`.
- **Delete dead code** (each verified zero-referenced): `eacl.datalevin.integrity` (orphan byte-copy), `eacl.datomic.codec` (superseded by `secure-format`), the `eacl.datomic.consistency` remnant, the duplicate private `relationship-seq` in orchestration, five unreferenced vars, the 5 stale `exploration/` duplicates of live `formal/stable-discovery` bridges, and orphan test/bench namespaces. Remove ~2.3 GB of untracked working-tree detritus (937 MB TLC `states/` dump — also add to `.gitignore` — and a stale full-repo copy nested under an old change directory).
- **Repair and speed up the formal harness** (gates become falsifiable; wall-clock drops; proof authority unchanged): make the source-closure selftest able to fail; strengthen the mutation-tautology guard so literal-decidable controls are rejected and re-deliver those kills through real gates (all 15 decide today on adjacent literals; six can additionally discharge only through the `expected-*` duplicates of the very functions they mutate); run counterexample replay on a classpath where all 67 entries resolve, asserting completeness in strict mode (the skip-tolerance stays for module-isolated runs, where it is documented intent); make the Apalache mutation gate fail on an empty control set; deduplicate the double `compile-js`+`npm ci`; parallelize the 49 serial Dafny verify processes (per-file CSVs preserved); fix the 7×-per-file `slurp` loop and the double tree-`prewalk`; move the CI benchmark that gates a production-dead kernel operation to the weekly cron; schedule the shipped enumeration engine's currently-unexecuted proof gate (`verify-fast.sh`, 651 obligations) and fix its flaky 12 s wall-clock limit; correct stale `assurance_contract.clj` `:entry-points` and dangling counterexample ledger references.
- **Tooling hygiene**: clj-kondo config for the `with-request-engine` macro (removes a false "Unresolved symbol" error), fix the 22 outstanding kondo warnings.
- **Not changed**: algorithms, public APIs, wire/cursor formats, persisted schemas, client error contracts, the Dafny/TLA models' proof surface, the dormant-but-verified `IndexedTraversalKernel` seam, CLJS bundle composition, CI job names (release-guard pins them).
