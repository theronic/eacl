# Proposal: EACL v8 root-cause fixes — correct, fast, simpler

## Why

Two audit waves over `release/v8.0` (tip `codex/restore-v8-enumeration-performance @ 8b17ee0`) — six deep-dive audits followed by ten adversarial verification agents, several with empirical repros — found a small set of root defects that account for nearly every observed correctness and performance problem, including the 0tx consumer regression (38.1× point `can?`, 12.1× first page, 9.1× exact count vs v7 on populated recursion). The findings are recorded in `docs/reports/2026-08-07-eacl-v8-exploration-review.md` (Parts I and II) and `docs/reports/2026-08-07-eacl-v8-raw-recursive-performance-investigation.md`. v8.0 is pre-release: no migration path is owed, so the root causes can be fixed structurally instead of patched around.

The root causes (each verified with file:line evidence and, where noted, live repros):

- **R1 — validity keyed on whole-DB identity instead of dependency scope.** Cursor proof digests commit to `basis-t`, so *any* write forces cursor rebase, defeats the heads/continuation caches, and (because the schema check is skipped during recovery and stamps schema-version *as* basis-t) leaves cursors effectively unvalidated against schema generations on write-active databases.
- **R2 — the recursive route paginates an unstable order by dense ordinal.** Worklist derivation order is not a function of the result set; rebase resumes at position+1 in the *current* denotation, silently skipping and duplicating pre-existing, still-authorized results under order-perturbing writes (confirmed high; no theorem bounds the divergence).
- **R3 — a confirmed single-flight deadlock** (empirically wedged: fair untimed semaphore acquired inside the flight delay's lock, unbounded flight registration, cross-thread joins under held permits). Absorbing state; reachable with virtual threads/async dispatch or lowered `max-inflight`.
- **R4 — the raw API recompiles everything per call**: two content schema proofs per list/count (client path: three), 2–3 recursive-plan compile+certify runs, 57 cold permission-path walks, and denotation cache-key construction against a nil store (all confirmed by instrumentation).
- **R5 — the generated kernel's one-command-per-scan protocol**: 2 FFI crossings per frontier stream, ~98% of which are emptiness probes realizing zero datoms; chunk/fuel tuning measured at a 1.5% ceiling. This is the intrinsic layer of the 0tx regression (4.6–7.8× with schema/plans hot).
- **R6 — completed-answer caches are unbounded in bytes** (the weight function is accepted and ignored; 1024 × 1000-item pages measured at 95.5 MB, up to ~930 KB/entry at max page size) with arbitrary hash-order eviction and an admission filter that freezes into a fixed hash-lucky set (measured 2.3% admit at 50k keyspace).
- **R7 — Datahike/DataScript are a 73–92% identical fork pair** with live behavioral drift (nil-typed anchor filters act as wildcards returning rows from every relation definition on DS/DH; divergent error contracts; divergent option maps; ~4,700 lines of pure orchestration duplicating the 21-operation SPI).
- **R8 — the CLJS production path is broken and slow**: 591 KB foreign-lib (13% provably dead), `:advanced` compilation fails at runtime (zero externs for 452 access sites, CI builds only `:none`), ~31 µs/result through the boundary (~31 s per 1M-result enumeration), with EACL's own `dafny-seq.js` Proxy shim contributing 76% of per-element read cost.
- **R9 — the highest-risk cache path is live but undocumented and under-tested**: managed cross-revision denotation reuse works (closure verified complete), yet the docs claim it is disabled, no randomized cached-vs-uncached oracle runs with the managed tier active, and DataScript silently defaults to the writer-contract-dependent `:managed` mode (stale allow demonstrated with one raw `ds/transact!`).
- **R10 — gate and hygiene debt**: no performance gate exercises populated recursion (the "50k recursive" gate does zero recursive work); the TLA mutation-kill controls and the explorer gate are wired into no CI workflow; dead code sits on trusted surfaces (proof-descriptor envelope path, `watermark.clj`, zed-v2, `Pagination.dfy` models an algorithm production does not implement); verified decisions receive hard-coded `true` inputs; default HMAC keys are process-local with no startup warning.

Correctness first, then speed, then simplicity — this change delivers all three: R2/R3/R9 are correctness; R1/R4/R5/R6/R8 are speed; R7/R10 and the deletions inside R1/R2 are simplicity (net: the ordinal-cursor machinery, ~350 lines of engine code, a handwritten trusted chunk orchestrator, one of two page-token codecs, and four dead namespaces/option surfaces are removed).

## What Changes

- **BREAKING** (pre-release, sanctioned): portable cursor envelope version bumps (v10→v11); the `:recursive-traversal` cursor kind is deleted — both routes emit keyset `:lookup-eid` cursors in internal-eid order; recursive `:desc`/`:last` restrictions are lifted; outstanding pre-change cursors fail with typed `:eacl.pagination/invalid-cursor`.
- **BREAKING**: cursor continuation proofs become dependency-scoped (relation stamps, not `basis-t`); the stale-schema validation runs unconditionally (it is currently bypassed exactly when it could fire); unrelated writes yield `UseCurrent` instead of `RebaseCurrent`.
- Single-flight coordination is restructured so no thread ever blocks on the computation semaphore while holding a flight delay's lock (mechanism per design.md, chosen from verified alternatives); a deterministic wedge-regression test is added.
- Raw-path request-local evaluation context: one schema proof per request (adapter-level memo), one recursive-plan compile+certify per request, nil-store short-circuits before any cache-key work; client path drops from 3 proof reads to ≤2.
- Kernel-boundary efficiency, phase 1 (host-only): hoist per-crossing `IndexedLimits`/fuel marshalling, key the type catalog by raw `DafnySequence`, intern empty scan responses, drop the redundant host per-value walk in favor of the certified kernel validator. Phase 2 (Dafny, gated on the populated-recursion gate still failing 2.0×): wave-batched scan commands (`drive` returns a bounded command batch; `resume` folds ordered responses).
- Completed-answer caching folds into the weighted `SubproblemStore` as a third tier: byte-bounded, honestly LRU, exact/managed layering unified; `bounded-assoc`, `admit-entry?`, and the frozen admission map are deleted.
- **BREAKING**: backend de-fork — Datahike/DataScript client orchestration (the nine per-backend operation fns, filter validation, integrity, endpoint codec usage) collapses into shared core parameterized by the 21-operation SPI; Datomic's private relationship-page reimplementation moves onto `eacl.engine.relationships`; the shared anchor validator adopts value-presence (`some?`) semantics with `:nil-anchor-keys` ex-data on all backends; one cursor-token codec (AEAD) with a startup warning when keys are defaulted.
- **BREAKING**: DataScript `:coherence-authority` handling changes per design.md (explicit choice or safe default — decided from the verification wave); managed-tier docs corrected to state that cross-revision denotation reuse is live and under what contract; a randomized cached-vs-uncached differential oracle runs with the managed tier active on all three backends.
- CLJS production engine decision implemented (per design.md): the browser path stops shipping the 591 KB BigNumber foreign-lib on the hot path; a CI `:advanced` build and an absolute ns/result ceiling gate are added either way.
- Populated-recursion gate suite: star/chain/mixed/broad-union fixtures at 2k/10k, nine exact logical-work assertions (crossings law, proof/compile counts, nil-store zero-key-work, continuation resumption, count-publishes-denotation, point-check locality, linearity), matched-v7 latency baselines with the 2.0× bound, cache-maintenance op-count invariants; CI additionally wires the existing-but-dormant explorer 10k gate and `apalache-mutation-control`.
- Trusted-surface hygiene: delete the dead proof-descriptor envelope path, `watermark.clj`, zed-v2 constructors, `:shared-cache-store`/`:lookup-cache-store` options, and the relay `:path-frontiers` branch; retarget or delete `Pagination.dfy`; pass real values (not literals) to `DecideContinuation`; rate-limit/optionalize the hot-path schema warning; enable `*warn-on-reflection*` in CI; document the GCM nonce rotation bound.

## Capabilities

### New Capabilities
- `single-flight-coordination`: wedge-free deduplicated subproblem computation — no deadlock under any thread count, bounded concurrent execution, honest hit/join metrics.
- `keyset-recursive-pagination`: recursive enumeration emits internal-eid keyset order with `:lookup-eid` cursors; no skip or duplication of surviving results across pages; O(log n) membership; counts publish denotations; route-change-tolerant cursors.
- `cursor-dependency-validity`: cursor continuation proofs scoped to the query's relation dependency stamps; unconditional schema-generation validation; one AEAD token codec; defaulted-key startup warning.
- `raw-request-context`: raw API calls perform at most one schema proof and one plan compile+certify per request, and no cache-key work against absent stores; nothing outlives the request or crosses snapshots.
- `kernel-boundary-efficiency`: reduced and amortized FFI crossings for generated traversals, with logical-work gates enforcing the crossing law.
- `answer-cache-bounding`: completed answers byte-bounded under the weighted store with true recency eviction and working admission.
- `managed-reuse-certification`: managed cross-revision reuse documented as shipped, differentially tested under interleaved writes, with an explicit, safe coherence-authority posture per backend.
- `backend-unification`: one shared client orchestration over the 21-operation SPI; uniform filter validation, error contracts, and option surface across Datomic/Datahike/DataScript.
- `cljs-production-engine`: a browser path that compiles under `:advanced`, ships without the BigNumber foreign-lib on the hot path, and is held to an absolute per-result ceiling.
- `recursion-performance-gates`: populated-recursion fixtures and exact logical-work/latency gates in CI, including the currently dormant TLA mutation controls and explorer gate.
- `trusted-surface-hygiene`: dead code removed from trusted surfaces; verified decisions receive real inputs; formal models correspond to shipped algorithms.

## Impact

- **Code**: `modules/eacl` (`engine/v8.cljc`, `subproblem_cache.cljc`, `cache.cljc`, `verified_kernel.cljc`, `relay.cljc`, `cursor.cljc`, `continuation.cljc`, `relationships/filters.cljc`, `formal/production_kernel.clj|_js.cljs`), all three backend modules (core/impl/backend files; large deletions in eacl-datahike and eacl-datascript from the de-fork), `formal/dafny` (phase-2 batching: `IndexedTraversal.dfy` + completeness/refinement modules; deletion pass: `PageWindow.dfy` rebase family, backward-render mode, `Pagination.dfy`), `bin/` and `.github/workflows` (gates, `:advanced` build, mutation controls), docs (`cache.md`, `v8-subproblem-cache.md`, release notes).
- **APIs**: cursor token format (breaking); DataScript client construction (per design decision); backend option-map unification (renames consolidated); `read-relationships` nil-anchor error contract unified to Datomic's.
- **Consumers**: 0tx's raw-path usage becomes viable for populated recursion (target: ≤2.0× matched v7 on the new gates after phases 1–4, parity-or-better after phase 2 batching if triggered); its own report's P0/P1 recommendations are all covered here.
- **Formal story**: net trust reduction — the handwritten rebase chunk orchestrator and the dead authenticated-envelope path are deleted; sortedness enters only at the host boundary where the existing certified `DecideAcyclicPage` already validates every slice; phase-2 batching is the only new proof work and is explicitly gated on measured need.
- **Target tree**: implementation lands on the v8 lineage (`release/v8.0` / PR #104 successor), not `main`.
- **Supersession**: this change supersedes the open/prior OpenSpec changes where they overlap — `restore-v8-enumeration-performance` (extended by `kernel-boundary-efficiency` + `recursion-performance-gates`; its non-goal of touching the genuinely-recursive engine is deliberately reversed here), `add-verified-subproblem-cache` (extended by `managed-reuse-certification` and `answer-cache-bounding`), `redesign-cross-backend-freshness-cache`, `add-intelligent-eacl-cache`, `add-consistency-aware-eacl-cache`, and `harden-v7-4-cache-consistency` (v7-era cache candidates, already partly superseded in-tree), and `upgrade-datascript-datahike-to-v8` (subsumed by `backend-unification`). The v8 tree's main spec `modular-backend-workspace` remains valid; `backend-unification` tightens it (single shared orchestration) rather than contradicting it. These existing artifacts live in the v8 lineage's `openspec/`; where their requirements conflict with this change, this change wins.
