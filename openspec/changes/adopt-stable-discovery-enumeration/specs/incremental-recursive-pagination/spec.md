# incremental-recursive-pagination Specification

## REMOVED Requirements

### Requirement: The certified route fixes public order and cursor ABI
**Reason**: The stable-discovery engine routes every permission root through one sealed plan and one generic width-one reducer; there is no acyclic route, routing certificate, entity-ID merge, generated indexed traversal, fuel quantum, or route-specific public order. Public order is the stable first-discovery order carried by `:stable-edge` cursors (see `stable-discovery-enumeration`).

**Migration**: None. The requirement described a mechanism the stable-discovery engine removed; consumers see the `:stable-edge` contract in `stable-discovery-enumeration`.

### Requirement: Recursive order is a deterministic logical ABI
**Reason**: Superseded by the sealed plan's composite fingerprint and order contract; the recursive-logical cursor kind and order ABI 2 are retired.

**Migration**: None. The requirement described a mechanism the stable-discovery engine removed; consumers see the `:stable-edge` contract in `stable-discovery-enumeration`.

### Requirement: Fuel boundaries preserve recursive traversal progress
**Reason**: The reducer has no fuel quantum; progress is preserved by history-free checkpoints (complete reducer state plus the undelivered lookahead segment) and governed deterministic replay.

**Migration**: None. The requirement described a mechanism the stable-discovery engine removed; consumers see the `:stable-edge` contract in `stable-discovery-enumeration`.
