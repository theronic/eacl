# Stable discovery loophole audit

Status vocabulary follows the useful part of Lore's discipline:

- **proved-model**: a replayable formal model establishes the named abstract
  claim;
- **checked-source**: executable source/adapter evidence agrees, but this is
  not a source-refinement proof;
- **measured**: a pinned workload/topology produced the observation;
- **unknown**: evidence is deliberately withheld;
- **refuted**: a counterexample killed the proposed claim.

Functional semantics, logical work, retained logical state, JVM bytes,
physical operations, and wall time are separate claims. No row inherits a
stronger status from another resource dimension.

| Area | Loophole / strongest attack | Required design response | Evidence and current status |
|---|---|---|---|
| Denotation | Dropping global EID merge could change who is authorized. | Define authorization as the least fixed point; define discovery order separately. | Least reachable closure and order irrelevance are **proved-model**. Production source refinement remains **unknown** until the new compiler exists. |
| Language | Unary reachability would be wrong for conjunction, exclusion, caveats, or non-monotone rules. | The v8 engine accepts only the finite positive union/relation/permission/arrow fragment; unsupported operators fail closed. | Four accepted rule forms are grounded **proved-model**; accepted-source normalization parity is currently only **checked-source**. |
| Arrow grounding | An arrow-permission appears binary because it needs a permission grant and a relationship. Omitting resource-type equality repeats EACL's documented historical formal bug and admits cross-type grants. | At a fixed basis, each actual type-valid via relationship grounds one unary edge from a type-valid intermediate grant to a type-valid head grant. Carry node types, relation resource types, allowed subject types, and entity types explicitly. | Exact typed direct/arrow-relation bases and self/arrow-permission edges are **proved-model** in a 6-obligation leaf; 20,000 typed executable cases pass and the historical missing-type-guard mutant is **refuted**. |
| Forward joins | Removing dynamic consumer/grant buckets might miss a rule registered after a grant, an offset cursor might skip/repeat a static consumer, duplicate sealed IDs might alias logical work, or lazy arrow scans might fail to refine the fully grounded closure. | Forward consumers are a complete immutable reverse rule index in the sealed plan; unique rule IDs are a validated plan invariant; the cursor advances monotonically over the exact indexed vector; each typed producer consequence must equal one grounded outgoing edge. | Grounding, exact index membership/unique-ID/prefix/exhaustion, and lazy-producer-to-ground-edge equivalence are **proved-model**; the focused producer leaf has 4 obligations in 1.08 s. 20,000 independent indexed-cursor/typed-producer cases pass and drop-last/duplicate-ID mutants are **refuted**. Exact Clojure plan-index refinement is **unknown** for the replacement compiler. |
| Static reverse traversal | A generic fixed-point implementation can make immutable rules appear as a second dynamic join side, creating unnecessary buckets and Cartesian pair work. | Index every rule by head node in the sealed plan. Starting from the root grant, emit exact transposed predecessor goals and base-owner scans into one exact-admission stack. | Producer exactness plus 16 static-frontier obligations are **proved-model**; eight recursive source-shaped cases match an independent oracle and all frozen engines. Production descriptor conversion remains pending. |
| Reverse type domain | A `(permission-node, resource-eid)` goal is invalid when the node's resource type differs from the entity type. | The sealed producer may emit only valid typed grants from certified relation definitions; adapters preserve internal/external type identity. | Typed grounding and reverse-producer exactness are **proved-model**; the cross-type arrow mutant is **refuted**. Production conversion remains pending. |
| Reverse denotation | Sound local reverse rules can still be incomplete, traverse the wrong relationship direction, or rely on an unstated numeric packing of typed grants, so `lookup-subjects` may disagree with `can?`. | Define forward authorization as a principal-owned typed grant reaching the root. Production source refinement remains pending. |
| Result dedup | Distinct derivations can project to the same external EID. | Admit exact logical grant identity once. For a fixed query, the canonical root grant identity is injective in the returned EID; fail if an adapter violates total/injective identity mapping. | Forward/reverse root identity is **proved-model**. Production compiler/adapter enforcement remains **checked-source**, not proved. |
| Cycles | Recursive schemas or data can run forever. | Exact admission accepts each logical occurrence once. A nonterminal physical chunk advances and replaces that occurrence without completing or readmitting it; a terminal chunk completes it once. Scan positions strictly progress. | Finite logical closure and fresh logical completion are **proved-model**; residual admission/completion/progress are **proved-model** in `LogicalScanCursor.dfy`. Physical backend termination is separate and **unknown** where no timeout/cancel guarantee exists. |
| Memory lower bound | Stable exact pagination might be stateless after abandoning sort order. | Retain exact admitted state or replay/checkpoint it. Approximate filters may accelerate but never authorize suppression. | Exact-state lower bound is an information argument; reducer retained logical work `<= |V|` is **proved-model**. JVM-byte bounds are **unknown**. |
| Result state | A separate emitted-EID set might still be needed. | Use injective root work projection and the admitted set. | Generic emitted state was removed; the smaller reducer is **proved-model** with 24 obligations. |
| Result-history retention | An observation-rich proof state can silently become a runtime/checkpoint requirement and retain every result ever discovered, or a correct core can be paired with the wrong pending segment or target stop. | Treat the complete sequence as ghost observation only. Refine to stack, exact admission, scalar count, and one output; buffer only the target suffix/page plus validation lookahead; require scalar progress, observed prefix, cursor, and pending boundary to agree. | Erasure is **proved-model** in 9, combined concrete hot-loop refinement in 7, targeted response driving in 14, bounded page/lookahead in 14, and exact checkpoint composition in 6. The `>` stop mutant is **refuted**. Production heap/source refinement remains pending. |
| Transient ownership | Persistent HAMT/vector updates allocate heavily, but an aliased or post-freeze transient would corrupt immutable cursor branches; current Clojure bytecode does not enforce same-thread ownership. | One canonical reducer owner mutates request-local builders for the complete concrete state. Freeze before caching, publication, cancellation handoff, or thread handoff; revoke the old branch; fork independent transients from persistent snapshots. Physical workers never receive builders. | Full-state ownership/freeze/fork isolation is **proved-model** with 12 obligations; Clojure branch/use-after-free controls pass. At 100,000 flat admissions the transient microbenchmark reduced allocation from 75.8 MB to 15.9 MB and time from 14.7 ms to 9.4 ms. Production CLJ/CLJS refinement and retained heap remain pending. |
| Page-size admission | A `page-size + 1` theorem is not a service memory bound if a caller can request an enormous page or replay a cursor minted under a retired cap. | Validate a positive configured maximum before cursor minting, buffer/checkpoint allocation, and replay; authenticate the chosen size and reject cross-size reuse. | Buffer cardinality relative to page size is **proved-model**; configured-cap enforcement and reservation accounting remain source/operational qualification. |
| Rule order | Map iteration, hash seeds, runtime byte sorting, or worker timing could change pages or allocate on the hot path. | Assign portable canonical rule ordinals once; seal static vectors in validated `(read-rank, ordinal)` order; reverse the canonical successor vector once when appending it to the right-edge stack; preserve certified backend scan order and reducer admission order compositionally; bind the full order ABI/fingerprint into cursors. Runtime traversal performs no sort or canonical-byte comparison. | Order irrelevance, rank certification, exact vector uniqueness, and concrete right-edge trace composition are **proved-model**. Membership-only, rank-only, duplicate-ordinal, and push-without-reverse controls have constructive counterexamples. The exact source contract is specified in `CANONICAL_ORDER_CONTRACT.md`; portable production vector/fingerprint and adapter scan-order refinement remain **unknown**. |
| Rank optimality | A local “direct before arrow” heuristic can choose a long remote chain over a cheap productive branch. | Certify shortest remaining static 0/1 read distance with edge inequalities plus a well-founded witness successor/hop count. | Shortest-distance certificate is **proved-model**; 20,000 cyclic generators match independent Dijkstra; missing inequality/hop mutants are **refuted**. |
| Rank cycles | A zero-read alias cycle can make a witness loop forever. | Require strictly decreasing witness hops even when distance does not decrease. | **proved-model**; no-hop mutant **refuted**. |
| Rank numeric bounds | Dafny naturals do not overflow, but malformed host integers can overflow or lose precision before a Clojure/CLJS checker rejects them. | Validate positive bounded counts, array lengths, node/rule ordinals, distances, hops, and fixed edge costs before indexing or arithmetic; require distance/hops `< node-count`. | Bounded fields are part of `ValidCertificate`; the strengthened leaf remains **proved-model** in 1.02 s, and an oversized-hop mutant is **refuted**. Source checked-arithmetic refinement remains pending. |
| Rank prediction | Static shortest read cost does not know emptiness, cardinality, cache residency, or latency. | Treat rank as deterministic lower-bound scheduling, not an oracle; enforce logical/physical limits and benchmark empty-prefix cases. | Universal dominance is **refuted** by DFS/FIFO counterexamples. Workload benefit is **measured** only on adversarial fixtures so far. |
| Chunking | Adapter chunk width changes first-discovery order when a recursively explored early value reaches later scan values in a different order. A dropped buffer can also skip values if resume uses the physical fetched-end instead of logical progress. | Consume exactly one ordered scan value per reducer transition; store the exact logical exclusive bound in authoritative state; keep fetch width/end and response offset in a detachable request sidecar. | Eager-width independence is **refuted** by a formal/source overlap fixture (`[a c b]` versus `[a b c]`). One-value width independence and arbitrary dematerialization are **proved-model** in `OneValueScanNormalization.dfy`; 153 source-shaped retained/dropped-buffer comparisons pass over 17 recursive cases, and the wrong-resume-position control is killed. Production sidecar refinement remains **unknown**. |
| Deep sidecar retention | One buffered broad scan per recursive depth can retain roughly 627--634 bytes/depth at width 64 even though logical frames are compact. | Apply a fixed per-request newest-retained sidecar count plus the service-wide weighted response cap. Eviction drops only the accelerator; the logical bound remains. Initial remote candidate is 16 buffers (about 10 KiB in the measured fixture), while effective width one retains none. | `BoundedSidecar.dfy` proves unique newest retention within capacity in 10 obligations. A 100,000-depth source-shaped campaign checked capacities 0/1/4/16 over 400,000 transitions and retained at most 0/63/252/1,008 buffered EIDs. Actual production byte calibration remains **unknown**. |
| `has-next` | Returning a full page does not prove another result exists. | Perform exactly one-result semantic lookahead. If no later result exists, exhaust the remaining graph. | Correctness is **proved-model**; worst-case empty suffix cost is unavoidable and must be benchmarked. |
| Pagination | A boundary EID does not identify a position. Treating an edge cursor as a page-start boundary and subtracting page size overlaps pages when the terminal page is short. Resuming a history-free reducer at a backward page's exclusive end also cannot recover preceding results. Changing page size corrupts boundaries; a rolling prefix digest cannot prove suffix equality. | Authenticate exact sequence context, fixed positive page size, and each edge's one-based ordinal/boundary identity. `after end` resumes at `ordinal`. `before start` has exclusive end `ordinal-1`, resumes at `max(0, ordinal-1-page-size)`, runs forward through one validation lookahead, and returns the preceding prefix. Both modes slice one canonical sequence; navigation mode is not cursor identity. | Internal forward boundary/checkpoint composition is **proved-model** in 16+6 obligations. Relay edge arithmetic is **proved-model** in 29; edge authentication and drift rejection in 26; history-free `after`/`before` execution in 22, each about 1.1 s. The overlapping page-start and resume-at-end mutants are **refuted** formally and executably. Cursor MAC/AEAD and source determinism remain qualification assumptions. |
| New basis | Re-minting a cursor at the same EID on a changed DB could skip or duplicate results. | Continue only at the exact selected basis, or after a complete dependency proof establishes semantic equality for this query. Never remint from position alone. | Policy is design-level; backend historical retention qualification remains **unknown** for several topologies. |
| Progress reuse | Injecting sound partial facts can still reorder first discovery. | Cache a complete immutable reducer state at a deterministic transition boundary, not arbitrary partial denotation facts. | Checkpoint composition/prefix retention are **proved-model**; partial-as-denotation is **refuted**. |
| Subproblem denotation cache | A complete fresh subtree answer can be set-correct yet have the wrong sequence under the request's existing admitted set; filtering its results cannot reconstruct skipped/admitted transition order. | Cache only exact whole-request answers, exact request checkpoints, or equality-complete ordered successor projections that still pass through normal admission. Never substitute a flat subproblem denotation into enumeration. | `CacheBoundary.dfy` proves exact projection substitution and gives a complete equal-set/different-sequence counterexample in 7 obligations (0.87 s). Ordered-set and context-free-denotation executable mutants are **refuted**. Production cache routing remains pending. |
| Progress checkpoint publication | A queued publisher can retain many structurally shared states, publication after cancellation could continue authorization computation, and a half-written state is not resumable. | Freeze/capture an immutable semantic reference, calculate weight from stored counters, and synchronously atomically replace the in-memory latest checkpoint. No initial async queue or serialization. Optional later remote serialization uses separate bounded latest-only capacity. | Resume equivalence and atomic checkpoint lifecycle are **proved-model**; post-control/partial/old-epoch mutants are **refuted**. One latest 116,464-unit fixture retained 5.04 MB; 64 candidates retained 6.39 MB. Production cache-put latency is **unknown**. |
| Checkpoint replacement | A lower-progress concurrent request can erase newer progress. | Replace only on exact key and nondecreasing canonical transition ordinal. | **proved-model**; replace-older mutant **refuted**. |
| Checkpoint answer | A resumable state may be mistaken for a complete denotation. | Give progress and completed-answer artifacts disjoint types/keys; only exhaustion may publish an answer. | **proved-model**; as-answer mutant **refuted**. |
| Projection cache | A canceled request may finish a useful storage read, but cache ownership, live request ownership, and response-vector lifetime can diverge. | Publish only a fully successful, bounded, validated immutable chunk under exact descriptor/live epoch; keep one response-store object with explicit in-flight, pin, and reusable-cache owners; no semantic integration after cancel. | Read-ahead/epoch/owner lifecycle is **proved-model**. Adapter atomic-response and weighted-store refinement are pending. |
| Descriptor aliasing | Two equal-looking scans may differ by basis, physical range position, semantic consequence, or chunk ABI. Confusing the two meanings of “continuation” can make page 2 reuse page 1. | Logical identity includes the semantic consequence. The physical key includes backend/store, database, exact basis, operation/index, bounds, exclusive physical range position, projection, limit, and chunk ABI; it excludes only semantic consequence and transport request ID. | The two-level identity and non-aliasing of physical positions are **proved-model**; descriptor coalescing is **proved-model**. Replacement adapter equality tests, including a drop-position mutant, remain pending. |
| Same descriptor | Parallel cold copies can multiply S3 GETs. | At most one request-local physical flight per equality-complete descriptor; integrate each logical occurrence separately in canonical order. | **proved-model**; duplicate-flight mutant **refuted**; direct S3 amplification is **measured**. |
| Cross-request sharing | Identical requests can still duplicate reads across requests. | Omit cross-request in-flight sharing initially; bound aggregate capacity. Add sharing only with waiter/refcount/epoch proofs. | Deliberate non-goal; cost remains possible but bounded by admission. |
| Read-ahead order | Faster speculative completion could reorder public results. | Only the canonical reducer head integrates. Read-ahead state is host-owned and nonsemantic. | **proved-model**; integrate-any mutant **refuted**. |
| Capacity starvation | Speculation can occupy every worker and block the canonical head. | Permanent service-wide governor with a canonical reserve; never replace it while physical work remains. | Reserve/lifecycle are **proved-model**; reserve-lending and early-free mutants **refuted**. |
| Completed-response accumulation | Releasing a read-ahead slot or response reservation at I/O completion can accumulate arbitrarily many completed vectors behind a slow canonical head or across requests. Cache rotation can also free a chunk still pinned by a request; zero weights can bypass the governor. | Count active plus complete-unintegrated occurrences in each request window. Mapping declared weight to conservative JVM bytes remains a source/heap qualification obligation. |
| Cancellation | HTTP cancellation may stop EACL but not synchronous Datahike/S3 I/O. | Freeze semantic integration immediately; retain physical charge until actual return; apply admission backpressure. | Semantic freeze and accounting are **proved-model**. | Retry | A partial failed response or overlapping retry can corrupt the canonical scan. Production adapter refinement remains open. |
| Backend snapshots | Concurrent reads might observe different bases. | Adapter captures one immutable basis and certifies concurrent scan safety independently from chosen physical width. | 5,792 operations per in-process backend plus H2/PostgreSQL/DynamoDB-local widths 1/2/4/8/16 all matched sequential oracles (**measured**). | Direct S3 width | More concurrency may amplify node restores and latency. | Request-local coalescing; initial direct-S3 width 2–4; tune by topology, never advertise a universal width. | Local delayed MinIO knee and GET amplification are **measured**; production AWS distribution is **unknown**. |

## Confidence boundary

High confidence applies to the abstract semantic architecture: positive
grounding, deterministic reducer, exact admission/result uniqueness, reverse
transposed traversal, stable pagination, checkpoint resumption, rank certificates, and
canonical-only integration and one-value scan normalization. The fast gate
currently checks 536 Dafny
obligations, five TLC model families with nineteen required mutation kills, and
18,000 randomized checks including twenty-two executable mutation controls.
The former 451-obligation gate took about 4.94--5.39 seconds across three runs
(median 5.10 seconds), and the larger 160,000-check campaign took 6.07 seconds.
The current gate, after adding the manifest-checked public-schema, reusable
compiler, sealed-plan, framing, minimum cursor, direction-complete static
index checks, sealed-vector uniqueness, and concrete trace composition, took
about 7.8 seconds in three consecutive current 536-obligation runs; former
495-obligation runs took 6.16--6.52 seconds. The source bridges add 1,010 bounded schema/plan/scheduler/
checkpoint cases and contention rounds plus 26
cursor-context mutations without importing backend latency into the correction
loop.

The semantic need for reverse joins is resolved against them. Reverse prefix
scheduling still has a read-versus-deferred-stack tradeoff on deep sparse
chains, but that is an explicit performance/heap qualification gate rather
than an unresolved semantic architecture choice. Remaining gates are:

1. complete the specified production compiler-to-ground-model refinement
   bridge: public normalization and the reusable rule/forward-index seam now
   pass, while static rank/vector order, reverse indexes, descriptor identity,
   public traversal, and root-identity injectivity remain;
2. make the replacement satisfy the frozen old/byte/cost benchmark and the
   small DataScript allocation envelope;
3. execute the source/formal deletion plan in `CLEANUP_SCOPE.md` after those
   gates pass, leaving one semantic authority and one current formal model set;
4. qualify physical GET/PUT, heap, and latency envelopes on each primary remote
   topology without borrowing them from the semantic proofs.

The compiler refinement contract and cursor/checkpoint trust boundary are now
specified in `SOURCE_REFINEMENT.md` and `CURSOR_TRUST_BOUNDARY.md`. They remain
source-test obligations; neither is allowed to borrow proof status from the
abstract models.

Remote S3/DynamoDB calibration, JVM byte sizing, and physical cancellation are
release qualification gaps, not reasons to complicate the semantic reducer.
They must remain `unknown` until measured/certified and must select conservative
deployment profiles in the meantime.
