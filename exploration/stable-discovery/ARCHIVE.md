# Stable-discovery exploration evidence archive

This directory is a frozen evidence archive for the
`adopt-stable-discovery-enumeration` OpenSpec change (task 2.1). It preserves
the exploration corpus that previously lived only under gitignored
`target/exploration/stable-discovery/`: the accepted width-one reducer
prototype (`forward_runtime_prototype.clj`), the Dafny proof leaves, the TLA+
models and mutation configs, the executable bridges, the contracts and audits
(`CANONICAL_ORDER_CONTRACT.md`, `LOOPHOLE_AUDIT.md`, `ALTERNATIVE_AUDIT.md`,
`BENCHMARK_PROTOCOL.md`, `IDENTITY_BENCHMARK.md`, `PHYSICAL_BACKEND_AUDIT.md`,
`DATA_STRUCTURE_CONTRACT.md`, `CURSOR_TRUST_BOUNDARY.md`,
`SOURCE_REFINEMENT.md`, `FORMAL_CLAIM_GRAPH.md`, `FORMAL_ITERATION_POLICY.md`,
`CLEANUP_SCOPE.md`), and the
`backend-probes/` physical probe project.

Rules:

- **Read-only.** This is evidence, not runtime code. Nothing here is on any
  load path. Release assurance is ported selectively per task 3.1; do not edit
  files here to "fix" them — port them.
- **The prototype defaults to logical chunk width 64, a rejected
  configuration.** Its order evidence is valid only with logical release width
  pinned to one. See design Decision 5.
- Documents may reference each other by their old `target/exploration/...`
  paths; within this directory those references resolve relatively.

Deliberately excluded from the archive (regenerable run state and dependency
caches, ~79 MB at archive time; none of it is cited evidence):

- `m2/` — Maven dependency cache (~56 MB of jars/poms).
- `minio-data/`, `minio-lmdb/`, `tiered-width-*/`, `tiered-identical-*/`,
  `lifecycle-*/` — MinIO object-store and LMDB data directories produced by
  the physical probes; regenerated by the probe scripts.
- `tlc-*/`, `verify-*/`, `mutant-*/`, `tlc-runner-classes/` — TLC model-checker
  working directories (state/fingerprint checkpoints); regenerated from the
  `.tla`/`.cfg` sources archived here.
- `jvm-tmp/`, `vendor/` — JVM scratch and vendored third-party git checkouts.
- Probe and gate `.log` files — regenerable run output; every figure they
  produced is quoted in the audit documents above.

Provenance: copied unmodified from `target/exploration/stable-discovery/` at
the revision recorded in this commit; measurements were produced on
Apple M4 Max / Temurin JDK as recorded per document.
